# Talvy

- [Sitio oficial](https://talvy.me)
- [Jobs board][https://jobs.talvy.me)

Talvy ayuda a una persona a preparar y seguir candidaturas para oportunidades encontradas en portales de empleo en España. El usuario mantiene uno o varios Currículums estructurados; Talvy usa el currículum elegido para calcular el encaje de una oportunidad y generar una Candidatura lista para revisar y aplicar manualmente.
